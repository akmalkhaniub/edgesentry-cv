Shift summary

▶ How EdgeSentry runs on AWS architecture
Perceive · OpenCV 5Clean-plate differencing, Otsu threshold, morphology, connected components, centroid tracking, zone polygon test.
Decide · Amazon BedrockA tool-using safety agent reads the scene report, re-inspects PPE up close, and chooses an action. Code guardrails veto unsafe or unproven actions; a fixed policy takes over if the model is unavailable.
Act · S3 + SNSEvery action stores an evidence frame in a private, encrypted S3 bucket. Stops and approval requests are published to an SNS alert topic.
Operate · Lambda + CloudWatchOne Lambda behind a Function URL. Per-run metrics (latency, steps, guardrail blocks, accuracy) via CloudWatch; X-Ray tracing; a DynamoDB daily cap protects the public demo.
